Introduction

QueueBuster’s Khata was a new feature which was added to QueueuBuster android application.

Why Khata?

QueueBuster has customers from Retail Business, Restaurant Business, Grocery Stores, Spa and Salon, and more. QueueBuster’s major focus is on the unorganized retail industry like General store or Kirana store. This khata feature can be helpful for these merchants.

What is Khata?

There are Kirana stores in every corner of India, where loyal customers buy the products on credit. Shopkeepers maintain all the customer's credit in a notebook, this is where Khata can help.

For example : Sunil buys groceries everyday from Ratna Store. He pays for all the groceries bought in end of the week. Shopkeeper notes all the purchases Sunil made throughout the week in a notebook and recieves payment end of the week.

Khata can record all the transactions easily made with the customer which makes this process much simpler for the merchant. The merchant can also ask the customer to pay through SMS, Whatsapp, email, etc. anytime with a payment link.

User flow for Khata

We looked for products which were offering similar features. After researching we started to analyze how the merchants would be using it if this feature was built.

We found that there were two main transactions that will be performed by the users(merchant) :

  1. Give Credit
  2. Accept payment

We made this generic user flow for both the transactions.

Prototype

After a whole lot of wireframing, we decided to add an option to upload image (a bill or grocery image while purchasing, or an other) for every transaction. User(merchant) should be able to edit each transaction, but not for the transaction which is already paid online by the customer.
